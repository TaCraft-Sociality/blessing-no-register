# blessing-no-register
关闭皮肤站的**邮箱注册**，只保留第三方账号登录（QQ / GitHub / 微软，取决于你装了哪些插件）。

## 行为

| 场景 | 结果 |
|---|---|
| 登录页「注册」链接 | 移除 |
| 直接访问 `/auth/register` | 302 跳回 `/auth/login` |
| 提交注册表单（含手工构造的 POST） | 返回错误「本站已关闭邮箱注册，请使用第三方账号登录。」，不建号 |
| 第三方登录（QQ / GitHub / 微软） | 正常工作，不受影响 |
| 已有账号用邮箱 + 密码登录 | 正常 |
| 已有账号修改邮箱 / 密码 | 正常，个人资料页照旧 |
| 后台创建用户 | 正常 |

## 安装

把 文件解压后 放进 `plugins/`，后台 → 插件 → 启用「仅第三方登录」。

无需配置项，没有后台页面。

## 注意

- 关闭的是**注册入口**，不是登录。老账号一律不受影响。
- 不要同时把 BSS 的邮箱验证/找回密码也关掉：已有账号忘记密码时，找回密码仍然需要发信。

## 文件

```
lang/                         中英文案
```
